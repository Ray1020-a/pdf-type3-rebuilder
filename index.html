PDF 字型急診室

中文 PDF 開啟很卡、放大模糊、載入很久,十之八九是內部藏了破碎的 Type 3 向量字型——每個字都要即時運算筆畫,頁數一多就撐不住。這裡會先幫你數清楚有幾個 Type 3 字型,再把整份文件點陣化重組成乾淨的新 PDF。所有運算都在你的瀏覽器裡完成,檔案不會上傳到任何地方。
